Missing values

Exploring missing values, and developing and validating the model with multiple imputation by chained equations instead of complete cases.

Question. 108 patients of the heart cohort lack cholesterol or body mass index, and the previous examples simply dropped them. Is that harmless? What changes if the missing values are imputed?

Why it matters

Dropping patients with a missing value (complete-case analysis) loses information and, worse, can bias the model if missingness is related to the outcome. A prediction model also needs a rule for patients with missing values when it is used. Multiple imputation by chained equations is the usual remedy (Steyerberg 2019): each missing value is filled in several times from a model of that variable given all the others including the outcome, the analysis is repeated in each completed data set, and the results are combined.

Missingness that depends on the outcome would be a warning against complete-case analysis. When the model is validated in a split or an external file, the table adds the share missing there.

Step 2: impute

Missing values: Multiple imputation, 5 imputations, 10 iterations. clinpred imputes numeric variables by predictive mean matching (an observed value of a similar patient), factors by logistic or multinomial regression, with the outcome in every imputation model (for Cox models, the event and its cumulative hazard (White and Royston 2009)).

R syntax 
r1 <- do.call(cpLogistic, c(args, list(missMethod = "mi", miM = 5)))

Performance is computed with the pooled model in each imputed data set and averaged; the bootstrap optimism is estimated within each imputation (Wahl et al. 2016), with the whole procedure — selection included — repeated in every resample. Validation data (a split or an external file) are imputed separately, so that no information from them reaches the model.

The other options

Method What it does When
Complete cases drops incomplete rows few missing values, unrelated to the outcome
Missing category / indicator a (missing) level for factors; for numeric variables, the development median plus an indicator predictor missingness that is itself informative and will also occur in practice (a test not ordered)
Single imputation one chained-equations imputation a quick look; standard errors too small
Multiple imputation m imputations, pooled the default choice for development

With the missing indicator method the model includes the indicators and stores the development medians; Export model writes both, so the published model can be applied to new patients with missing values.
